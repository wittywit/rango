# Cozy Rango (Studio Poetics): modification notes

See `INDEX.md` for the file and data.json structure map.

## What this is
A Construct 3 (Scirra) **web export** of a 2D platformer. Rango, a cat (sprite object named `Dude`), searches a valley of flowers for her sister Nila. The `.c3p` source project is NOT in this folder. Viewport 1920x1080, landscape, fullscreen PWA, with touch controls (HUD_left, HUD_right, HUD_jump).

No git repo, no package.json, no build step. Plain static files.

## Layout
- `index.html`: loader. Alerts if opened via `file:`; must be served over HTTP.
- `data.json` (1.1 MB): the whole game (objects, layouts, event sheets, audio list) as nested arrays. Only place gameplay can be changed.
- `scripts/c3runtime.js` (engine, 1.8 MB) and `scripts/main.js` (loader). Do not edit.
- `workermain.js`, `style.css`, `appmanifest.json`.
- `images/` (webp sheets: dude-sheet0/1, fairy, fairy_card, eye1, stage1_enemy, stage1_fly, tiledbackground1-4, shared-0/1/2), `media/` (~45 webm audio), `fonts/` (Rounded Elegance, Nunito, Cute Dino), `icons/`.
- `sw.js` + `offline.json`: service-worker offline cache.

## data.json structure (`{"project": [...]}`)
- `[0]` name "Cozy Rango", `[1]` first layout "Menu".
- `[2]` plugin declarations.
- `[3]` object types (230). Names are prefixed by stage or role: `Stage1_*`, `Stage2_*`, `HUD_*`, `Dude`, `Keyboard` (idx 4), `Touch` (idx 24). `Dude` carries a behavior (id 454753445950263, type "key"/Platform-style).
- `[5]` layouts. Levels named "1" to "24" (width 24000 or 36000, height 1080). Extras: `night02`, `B2`, `bw1`, `bw02` (48000), `Pink01`, `Temp_01`, `temp03`, `Menu` and `Selectlevel` (1920 wide). Typical layers: Sound effects, Background, Particles, Ground/Game/Dude, Leaf layer, HUD, Popup, Touchcontrols.
- `[6]` event sheets: `eGame` (72 top-level events, shared by levels), `eMenu`, `eLevel`. Each is `[name, [events...]]`.
- `[7]` audio list, `[8]` media folder "media/".
- Event encoding: `[0,0,false,null,id,sid,[conditions],[actions],[subevents]]`. Conditions/actions start `[type, objectIndex, ...]`. Object index values refer to `[3]` positions, but my decode of indices in eGame looked inconsistent (likely some object entries are offset or families), so cross-check before relying on it.
- Globals: eGame has `Gem`(0), `Playerhealth`(3), `State`(text), `Sound`("on"), `Music`("on"). eLevel has `Level`(1).

## How to modify
- Small tweaks (health, text strings, layout sizes, object positions): edit `data.json` carefully (use a Python `json` load/modify/dump with no formatting changes beyond what is needed; keep a backup copy first), then bump `offline.json`.
- Anything structural (new levels, new logic, art): needs the original Construct 3 project. Ask for the `.c3p`.
- Do not hand-edit `c3runtime.js`.
